# KNATURE 로컬 테스트 시나리오

> 1차(MVP) + 2차 Wave1(적립금·쿠폰·등급) + Wave2(게시판/CS) + Wave3(SCM) 전체 기능 검수용.
> 순서대로 진행하면 앞 시나리오의 데이터가 뒤 시나리오의 입력이 됩니다.

## 0. 사전 준비

### 서버 실행
`start-all.bat` 더블클릭 (또는 4개 터미널). API 기동 30초~1분 대기.

| 서비스 | 주소 |
|---|---|
| FO 쇼핑몰 | http://localhost:5174 |
| BO 관리자 | http://localhost:5173 |

### 계정
| 구분 | 아이디 / 비밀번호 | 비고 |
|---|---|---|
| BO 최고관리자 | `admin` / `admin1004` | 전 메뉴 접근 |
| BO 공장관리자 | `factory1` / `factory1234` | 그린코스 제1공장 — 발주/공장재고만 |
| FO 회원 | `benefit1` / `benefit1234` | 박혜택 · 루비 등급 · 적립금 약 3,000P |
| FO 회원 | `qauser01` / `qapass1234` | 김테스터 |

### 현재 데이터 상태 (시나리오 반영됨)
- 상품: **수분진정 토너 300ml만 판매중 (재고 65, 안전재고 30)**, 나머지는 품절/숨김
- 공장: 그린코스 제1공장 (토너 매핑: 단가 8,000 / MOQ 50 / 리드타임 4일), 공장재고 토너 50
- 쿠폰: WELCOME(가입 20%, 상한 3만) / 공지 1건·FAQ 1건·후기 1건 존재

## 시나리오 A. 신규 고객 첫 구매 여정 (FO)

**A-1. 회원가입** — FO 우상단 [회원가입]
1. 약관 체크 없이 [동의하고 다음] → ✅ "필수 약관에 모두 동의" 차단
2. 약관 2개 체크 → 다음 → 정보 입력 (비밀번호 확인을 다르게 입력) → ✅ 불일치 차단
3. 올바르게 입력 + **[주소 검색]** 버튼 → ✅ 다음(카카오) 우편번호 팝업 → 주소 자동 입력
4. 가입 완료 → ✅ "OO님, 가입을 환영합니다!"

**A-2. 가입 혜택 자동 지급** — 로그인 → 마이쇼핑
- ✅ [적립금 내역] 가입적립 +5,000P
- ✅ [쿠폰 내역] "신규가입 20% 할인쿠폰" 사용가능 1장

**A-3. 상품 탐색**
1. 메인: 배너(10초 자동 전환), 라인 탭 클릭 → 상품 필터링
2. 품절 상품 → ✅ SOLD OUT 배지 + 상세에서 구매 버튼 비활성
3. 헤더 검색창 "토너" → ✅ 검색 결과 1건

**A-4. 옵션 상품 주문 (쿠폰+적립금)**
1. 토너 상세 → 옵션 없이 [바로구매] → ✅ "옵션을 선택해주세요"
2. 옵션 "500ml 리필(+8,000)" 선택, 수량 2 → ✅ 총액 70,400원 자동 계산
3. [장바구니] 담기 → ✅ 헤더 배지 수량 증가 → 장바구니에서 수량 +/- 변경 → ✅ 금액 재계산
4. [선택 상품 주문하기] → 주문서:
   - ✅ 주문자 정보 자동 입력
   - 배송지 직접 입력(주소 검색 사용)
   - **할인 적용**: 쿠폰 선택 → ✅ 할인액 표시 / 적립금 1,000 입력(또는 전액) → ✅ 실시간 최종 금액 재계산
   - 결제수단 [무통장입금] → 결제하기
5. 주문 완료 → ✅ 주문번호(ORD-오늘날짜-순번) + **입금 계좌 안내** + 7일 자동취소 문구

**A-5. 마이쇼핑 확인**
- ✅ 주문 현황: 입금전 1
- ✅ 적립금 내역: "주문 사용 -1,000P" / 쿠폰 내역: 사용완료 전환
- ✅ 주문 조회(기간 버튼 1/3/6개월/전체) → 상세: 옵션명·금액·상태 플로우

## 시나리오 B. 관리자 주문 처리 + 연동 (BO ↔ FO)

BO(`admin`) 로그인.

**B-1. 주문 확인**
- 주문 관리 → ✅ A-4 주문이 목록에 (무통장/입금전) — 품목별 탭에서도 확인
- 상세 → ✅ 옵션명, 할인·적립금 반영된 결제금액

**B-2. 입금 확인 → 배송 처리**
1. 상태를 [배송준비중]으로 저장 → FO 마이쇼핑에서 ✅ 상태 반영
2. 상세에서 **송장 입력**(택배사+번호) → ✅ "배송중" 자동 전환 → FO 주문 상세에 ✅ 송장 + [배송 추적] 링크

**B-3. 배송완료 → 구매확정 자동화 (Wave1)**
1. 상태 [배송완료] 저장
2. FO 마이쇼핑 적립금 내역 → ✅ "구매 적립 N%" 자동 적립 (등급별: 뉴 0%/루비 1%…)
3. 총구매금액이 등급 기준 넘으면 → ✅ 헤더/마이쇼핑에 등급 자동 승급
4. BO 고객 관리 → 해당 회원 상세 → ✅ 총구매금액·등급 반영

**B-4. 취소 흐름 (역방향)**
1. FO에서 새 주문 1건(무통장) → 주문 상세 [주문 취소 신청] + 사유
2. BO 주문 상세 → ✅ "취소요청" + 관리자 메모에 고객 사유
3. BO에서 [취소완료] 처리 → ✅ **재고 복원**(재고 관리에서 수량 확인) + FO ✅ 적립금 환급/쿠폰 복구(사용했다면)

**B-5. 엑셀 다운로드**
- 주문 관리 [엑셀 다운로드] → ✅ .xlsx — 송장번호가 지수표기(1.2E+11) 없이 그대로, 금액 콤마, 컬럼 폭 자동

## 시나리오 C. 재고/품절 연동 (BO ↔ FO)

**C-1. 품절 처리** — BO 재고 관리 → 토너 [재고 조정] → 0 + 사유
- ✅ 판매상태 자동 "품절" / FO 새로고침 → ✅ SOLD OUT 배지, 구매 불가
- ✅ [이력]에 조정 기록

**C-2. 재고 확보 → 품절 해제** — 다시 재고 조정 → 40
- ✅ 자동 "판매중" / FO ✅ SOLD 해제

**C-3. 안전재고** — 재고 관리에서 토너 안전재고 값 클릭 → 예: 50 (현재 재고보다 크게)
- ✅ 목록에 "부족" 배지 / 대시보드 ✅ "재고 부족" 목록에 표시

## 시나리오 D. 게시판/CS (Wave2)

**D-1. 게시판** — BO 게시판 관리
1. 공지 작성(상단 고정 체크) / FAQ 작성(분류 선택) / 이벤트 작성(기간)
2. FO 상단 COMMUNITY → ✅ 탭별 노출, 공지 고정 배지, 아코디언 펼침
3. BO에서 노출 토글 [숨김] → FO ✅ 미노출

**D-2. 상품 후기**
1. FO 로그인(구매이력 없는 계정) → 토너 상세 후기 탭 → 작성 시도 → ✅ "배송완료된 구매 상품에만" 차단
2. **배송완료 이력 있는 계정**(benefit1)으로 작성(별점+내용) → ✅ 등록 + "적립금 500P 지급" → 적립금 내역 확인
3. 같은 상품 재작성 → ✅ "이미 작성" 차단
4. BO 문의/후기 → 후기 탭 → [블라인드] → FO ✅ 해당 후기 미노출

**D-3. 1:1 문의**
1. FO 마이쇼핑 [1:1 문의] → 작성 → ✅ "답변대기"
2. BO 문의/후기 → 미답변 필터 → [답변하기] 등록
3. FO 문의 펼침 → ✅ 답변 표시("답변완료")

## 시나리오 E. 쿠폰/적립금 관리 (Wave1 — BO)

**E-1. 쿠폰** — BO 쿠폰 관리
1. [쿠폰 생성]: 정액 3,000원 / 최소주문 20,000원 / 유효기간 설정
2. [발급] → 특정 회원(고객 관리에서 ID 확인) 또는 전체 → ✅ "N명에게 발급"
3. FO 해당 회원 쿠폰 내역 → ✅ 보유 확인 → 주문서에서 최소주문 미달 시 ✅ 선택 비활성
4. 사용 후 BO 쿠폰 목록 → ✅ 발급/사용 수 집계

**E-2. 적립금 수동 지급/차감** — BO 적립금 관리
1. 회원 검색 → [관리] → 사유 없이 지급 → ✅ 차단
2. 금액+사유 입력 [지급] → ✅ 잔액/이력 반영 → FO 적립금 내역 ✅ "[관리자]" 표기

## 시나리오 F. SCM 풀 사이클 (Wave3) ⭐

**F-1. 공장/매핑 확인** — BO 공장 관리
- ✅ "그린코스 제1공장" 존재 → [상품 매핑] → ✅ 토너(8,000원/MOQ 50)
- 새 공장 등록 + 다른 상품 매핑도 시도

**F-2. 자동 발주** — 발주 관리
1. 사전조건: 토너 재고 < 안전재고 (시나리오 C-3 상태면 충족)
2. [자동발주 실행] → ✅ "1건 생성" — 목록에 `자동` 배지, MOQ 이상 수량, 납기=리드타임 자동, "승인대기"
3. 다시 실행 → ✅ "0건" (진행 중 발주 중복 방지)

**F-3. 승인/반려** (admin)
- [승인] → ✅ 상태 "승인" / (다른 발주 만들어 [반려]·[취소]도 확인)
- ✅ admin에겐 공장확인/생산 버튼이 없음 (공장관리자 전용)

**F-4. 공장관리자 처리** — **로그아웃 → `factory1` 로그인**
1. ✅ 사이드바에 [발주 관리][공장 재고]만 표시
2. 발주 관리 → ✅ 자기 공장 발주만 / [공장확인] → [생산시작] → [출고통보] 순서대로 (건너뛰면 ✅ 차단)
3. 공장 재고 → 상품+수량 입력 저장 → ✅ 목록 반영

**F-5. 입고 + 검수** — 다시 `admin` 로그인 → 발주 관리
1. 출고 상태 발주에 [입고] → 입고 50 / 양품 48 / 불량 2+사유 / LOT 번호 / 유통기한 → [입고 확정]
2. ✅ 발주 "입고완료" / 재고 관리 → ✅ 본사 재고 +48, 이력에 "입고 (PO-…, LOT …)"
3. ✅ 공장 재고 -50 / 품절 상품이었다면 ✅ 판매중 자동 해제 → FO SOLD 해제
4. 대시보드 → ✅ 재고 부족 목록에서 사라짐(안전재고 초과 시)

**F-6. 발주서** — [발주서] 버튼 → ✅ 발주서_PO-….xlsx 다운로드

**F-7. 지역 기반 자동 발주 (주문 트리거)** ⭐신규
1. BO 공장 관리 → 그린코스 [수정] → 담당지역 `부산,경남` / 새 공장(예: 한강코스메틱) 등록 → 담당지역 `서울,경기,인천` + 토너 매핑(단가는 그린코스보다 **비싸게**)
2. 재고 관리 → 토너 재고를 안전재고+1 로 조정 (예: 안전 70 → 재고 71)
3. FO에서 배송지 **"서울…"** 주소로 토너 2개 주문 → 재고 69(≤70)
4. BO 발주 관리 → ✅ 새 발주가 **한강코스메틱**(지역 담당, 비싼 단가여도 우선) 앞으로 생성, 메모에 `주문 접수 트리거 (ORD-…) / 지역매칭: 서울,경기,인천`
5. 다른 주소(부산)로 추가 주문 → ✅ 진행 중 발주가 있으므로 중복 발주 없음
6. 담당지역 미매칭 주소(예: 제주)면 → 기존 규칙(최저 단가 공장)으로 발주

## 시나리오 H. 대시보드 기간별 매출 ⭐신규

1. admin 대시보드 하단 **매출 현황** 카드 → 기본 [일간](최근 14일) 라인차트 + 합계/일 평균 + 일자별 표
2. [주간] 클릭 → ✅ 최근 8주(월요일 시작) / [월간] → ✅ 최근 6개월 — 어느 탭이든 합계 금액 동일해야 함
3. ✅ 차트가 카드 폭을 가득 채움 (오른쪽 여백 없음)
4. `factory1` 로그인 → ✅ 대시보드 대신 발주 관리로 바로 진입 ("로딩중" 없음)

## 시나리오 G. 설정/계정/보안 스팟 체크

1. **설정 연동**: BO 설정 → 입금 계좌 변경 → FO 푸터/주문완료 안내 ✅ 반영 (상점정보·배송정책 동일)
2. **관리자 계정**: 설정 → 계정 등록 → 새 계정으로 로그인 ✅ / 본인 삭제 버튼 ✅ 비활성
3. **계정 찾기**: FO 아이디 찾기 → ✅ `qause***` 마스킹 / 임시 비밀번호 발급 → 새 비밀번호로 로그인
4. **회원정보**: 마이쇼핑 → 비밀번호 재확인 → 정보 수정/비밀번호 변경 / 배송지 CRUD(기본 배송지)
5. **권한**: 로그아웃 상태로 BO/FO 보호 페이지 직접 URL 접근 → ✅ 로그인 페이지로
6. **탈퇴**: (테스트 계정으로) 마이쇼핑 탈퇴 → ✅ 재로그인 불가, BO 고객관리엔 이력 유지

## 알려진 제약 (버그 아님)
- 실제 PG 결제창/본인인증/SNS 로그인 없음 — 카드·간편결제는 **모의 결제**(즉시 배송준비중)
- 임시 비밀번호는 메일 발송 대신 **화면 표시**
- 무통장 7일 자동취소는 매시 정각 + 서버 기동 시 실행 (즉시 확인하려면 서버 재시작)
